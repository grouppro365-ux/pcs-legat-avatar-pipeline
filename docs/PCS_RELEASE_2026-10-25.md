# PCS — исправления жизненного цикла мобильных окон, 25 октября 2026

Полное ТЗ остаётся открытым. Этот выпуск исправляет окна существующей CRM и галереи; не добавляет вторую CRM, инфраструктуру или платёжные интеграции.

## Исправления

- Карточка клиента и новая задача привязаны к конкретной форме и жизненному циклу окна. Закрытая форма с сохранённым DOM не может начать запись. Поздний ответ не закрывает новое окно, не записывает в него ошибку и не открывает старую карточку.
- Обновление CRM после успешного сохранения проверяет и маршрут, и окно перед изменением кеша. Завершение задачи не переключает оператора из нового окна.
- Ручное сообщение и follow-up принимают исходную форму при отправке. Сохранённый обработчик старой формы не может отправить текст из заново открытого черновика того же или другого клиента. Защита неизвестной доставки и стабильные идентификаторы повторов сохранены.
- Галерея каталога проверяет намерение открытия и текущую сессию. Поздние ответы, файловый диалог и завершение изменения не должны возвращать оператора в закрытую галерею или менять очередь другого объекта. После закрытия прекращаются оставшиеся загрузки пакета; уже отправленный запрос не объявляется отменённым. Старые кнопки не могут менять заново открытую галерею даже того же объекта.
- Ключи кеша четырёх изменённых модулей обновлены.

Проверено: все 1 199 регрессионных проверок прошли; независимый reviewer не нашёл блокирующих замечаний.

## Границы проверки

Регрессии воспроизводят задержанные чтения/записи, закрытие с сохранённым DOM, повторное открытие и замену окна. Они не заменяют приёмку в нативном Telegram/iOS и реальную доставку клиенту. Сообщения клиентам во время проверки не отправляются.

Проверка `SELECT 1` в существующем бизнес-проекте Neon 25 октября снова вернула HTTP 402: квота проекта/аккаунта превышена. SQL-миграции, рабочий видеозапуск через каноническую очередь и сквозная приёмка заблокированы этим внешним ограничением. Платёжный план не изменён; новая база для обхода лимита не создавалась.

## Видео — отдельный незавершённый выпуск

PR 110 остаётся черновиком: титры RU/EN реализованы через FFmpeg/libass, DejaVu Sans и закреплённый fontTools. 1 182 проверки и GitHub CI прошли для его исходного коммита. В production титры не включены. Нужны восстановление Neon, полный rollback QA, согласованный порядок SQL/worker/frontend/manager и реальный запуск версии 2 с редакторским просмотром точного результата.

Генерация LTX на существующем облачном GPU ранее подтверждена техническим роликом; это не доказательство завершения всей видеофабрики. Озвучка, работа с референсами бренда, полный социальный цикл, реальные показатели и обучение на результатах остаются открытыми.
