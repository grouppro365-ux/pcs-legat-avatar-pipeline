# PCS finance reads and CRM task editing

The Mini App finance route previously had no adapter handler. It now calls the existing authenticated manager and reads three distinct canonical sources: Supabase pcs_finance_entries, Neon settlements, and Neon quote_snapshots. The ledger has status filters; all sources have 100-row pages with lookahead, stable ordering, explicit failures, and narrow detail cards. Decimal amounts arrive as text and retain their original fraction and currency. No paid totals are inferred from quote snapshots, no currencies are added together, and private receipt paths, invoice keys, metadata, and full breakdowns are omitted. This is a financial viewing scenario, not payment acceptance, refund processing, or provider settlement confirmation.

CRM tasks can now be edited from the existing task queue or client card. A fresh contact-scoped task read supplies an exact microsecond version. The editor submits only changed title/comment/deadline/priority/assignee fields, converts the local date input to UTC, and preserves an unchanged deadline's precision. The server rejects identity changes, completed tasks, and stale versions; update and audit are one atomic SQL statement. Double submission is blocked, conflict drafts remain in the form, and a failed refresh cannot turn a successful save into an alleged failure.

Validation: 253 automated tests passed. Actual Neon task assertions ran with complete synthetic rollback (pg_net 174457, HTTP 200), covering client identity, partial-field preservation, UTC deadline, priority, stale writes, audit failure rollback, and completed-state rejection. Actual settlements and quote SELECTs returned HTTP 200 (174460, 174461). Supabase ledger fields and service_role SELECT permission were checked; direct ledger SELECT succeeded and currently returned no rows. Authenticated browser/Telegram REST E2E remains unverified; the ledger transport and text casting were checked in tests and against PostgREST's documented select cast syntax. No real customer messages, payments, or task edits were made.
