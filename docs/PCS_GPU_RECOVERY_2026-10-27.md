## Подтверждённый сбой аватара

GitHub run 40423155448 / job 121922262313 успешно запустил версию 102 существующего приватного Kaggle kernel. Провайдер перешёл из queued в running, затем в error. Старая сводка содержит CalledProcessError/OSError/PapermillExecutionError, без признака нехватки VRAM и без отсутствующего Python-модуля. Она смешивала текущие и прежние логи; утверждать, что текущую ошибку вызвал wrapt, нельзя.

## Изменения

- Каждая из 14 реальных кодовых ячеек исходного сжатого ноутбука записывает начало, завершение или ошибку этапа. Запись содержит только фиксированные названия этапов/статусов, разрешённый класс ошибки, errno и код возврата. Аргументы команд, портрет, голос, тексты и исходные ошибки в JSON не копируются.
- Диагностический файл записывается атомарно; сбой записи не заменяет исходную ошибку исполнения. Изменённые/отсутствующие/повторные маркеры этапов и некомпилируемый код блокируют подготовку ноутбука до запуска GPU.
- Сборщик показывает раздельно текущую версию, предыдущую и непривязанный лог. Он не публикует имя файла или сырые строки, читает ограниченные объёмы и принимает только точную схему отчёта этапа.
- Изменение patch_notebook.py запускает проверку аватара в существующем workflow/kernel. Изменение только LTX-инструментов сохраняет прежний smoke-сценарий. Выбор выполняется по git diff проверенных SHA; при ошибке сравнения GPU не запускается. Общая concurrency и ограничение одного запуска сохранены.

## Проверки

Все 1 200 регрессий прошли. Дополнительные Python-проверки выполняют реальную распаковку/подготовку ноутбука, компиляцию 14 ячеек, отказ при изменении структуры, безопасную обработку настоящего исключения и ошибки диска, строгую проверку отчёта, разделение ошибок версий и выбор workload на настоящей временной git-истории.

Это исправление наблюдаемости и воспроизводимой диагностики. Успешный рендер аватара, редакторская приёмка лица/синхронизации губ и завершение всей видеофабрики этими тестами не подтверждаются. Клиентские сообщения и публикации не отправляются.

## Реальная проверка версии 103

После слияния PR 112 выполнен GitHub run 40456746581 / job 122031743425, принят именно существующий приватный kernel версии 103. Его отчёт подтвердил `ECHO_RENDER / FAILED / CalledProcessError / returncode 1`: предыдущие этапы последовательного ноутбука прошли, сбой находится внутри рендера EchoMimicV2. Факт успешной генерации аватара не заявляется.

Запуск завершился ошибкой до success-only загрузки медиа; список артефактов содержит только `pcs-avatar-failure-diagnostics` (500 байт). Отмена не понадобилась и не засчитывается как выполненная. PR 113 исключил из будущих успешных артефактов приватные MP4, имена исходников и ffprobe-данные; в GitHub остаются только санитизированная диагностика и квитанция принятой версии. Видео сохраняется в приватном Kaggle.

Для уточнения причины без нового расхода GPU добавлен режим чтения лога одной принятой версии. Он не отправляет kernel, не ждёт GPU и не скачивает медиа; публикует только ограниченный отчёт. Диагностический сборщик теперь сохраняет начало и конец длинного лога вместо потери финальной ошибки за выводом установки зависимостей. Коды ошибок и подсказки компонентов фиксированы; приватные пути, сообщения исключений и аргументы не копируются.
