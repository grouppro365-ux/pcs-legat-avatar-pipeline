# Legat ABC Social Skill

Используй этот навык для Instagram, Facebook, Telegram, VK, Дзен и TenChat Legat ABC.

## Главная воронка

предложение → карточка Legat ABC → контент → дистрибуция → переход → обращение → ответственный → результат

## Приоритеты контента

- 45% реальные предложения;
- 20% подборки и сравнения;
- 15% полезность и доверие;
- 10% партнёры и supply;
- 10% сама платформа.

Если 3 из последних 5 материалов рассказывают о Legat ABC как о бренде, следующий материал должен быть про реальное предложение, сравнение или пользу.

## Языки

Операционные локали: RU, EN, PL, ES, ZH, JA, KO, TH, AR, FR, DE, KK.

12 локалей сайта не означают 12 длинных переводов каждого social post.

- глобальный Instagram: короткий EN на визуале + локализация caption только когда это действительно глобальный пост;
- market-specific: язык рынка + при необходимости короткий EN bridge;
- Telegram RU / VK / Дзен / TenChat RU: естественный русский.

## Каналы

### Instagram
Discovery. Reels для охвата, carousel для сохранений и сравнения, Stories для ежедневной жизни каталога.

### Facebook
Локальная дистрибуция, группы, обсуждение, партнёрские репосты. Не копировать Instagram дословно.

### Telegram
Конкретные предложения и быстрые обновления. Заголовок должен называть модель, район, категорию или другой известный факт вместо пустого кликбейта.

### VK
Русскоязычный охват, сообщества, Clips, подборки и опросы.

### Дзен
Evergreen, поиск и рекомендации: руководства, сравнения, полезные статьи, связанные с актуальными карточками.

### TenChat
B2B: партнёры, поставщики предложений, кейсы компаний, развитие рынков, упаковка каталогов.

## Fact gate

До публикации проверить:

- цену и валюту;
- availability;
- модель / объект / услугу;
- год / пробег / площадь / срок, если используются;
- город / страну;
- дополнительные платежи;
- право использовать медиа;
- актуальную landing page;
- что CTA не обещает больше, чем реально доступно.

Нельзя придумывать данные ради красивого текста.

## Safety language

Не писать:
- «100% безопасная сделка»;
- «гарантированно проверено»;
- «без риска»;
- «опубликуйте что угодно мгновенно».

Модель публикации Legat ABC контролируемая: предложение проходит предусмотренную проверку и согласование.

## Humanize

Удалять:
- «уникальная возможность» без причины;
- «идеальное решение»;
- «откройте для себя»;
- пресс-релизный тон;
- искусственные тройки;
- бессмысленные эмодзи;
- повтор одной мысли разными словами.

Предпочитать конкретную бытовую ситуацию, факты, одну мысль и один CTA.

## Visual

Использовать текущую светлую систему Legat ABC:
- white / off-white;
- very pale cool blue;
- deep navy;
- bright clean blue;
- cyan secondary;
- coral только для риска/предупреждения;
- реальные объекты;
- много воздуха;
- editorial marketplace.

Не использовать по умолчанию:
- black & gold;
- фиолетово-синий AI gradient;
- fake UI;
- fake rating / price / statistics;
- огромный логотип;
- банальные рукопожатия и глобусы.

## Publisher workflow

1. Получить подтверждённые факты.
2. Создать master angle.
3. Адаптировать текст по площадкам.
4. Создать visual/video prompt.
5. Проверить fact gaps.
6. Загрузить готовое или сгенерированное медиа в Postiz.
7. Сначала создавать draft, если материал содержит новые/изменчивые коммерческие факты.
8. После approval переводить в schedule/now.
9. Сохранять точную landing page и UTM.
10. После публикации собирать аналитику.

## Dzen route

Если Дзен подключён к Telegram через официальный Telegram crossposting route, публикация в выделенный Telegram-канал может использоваться как source для Дзена. Не утверждать, что Дзен опубликован, пока итоговая публикация не подтверждена.

## TenChat route

До появления собственного подтверждённого provider API использовать отдельный поддерживаемый publishing bridge. Не эмулировать логин/OTP и не хранить пароль пользователя в skill.

## Completion gate

Не считать материал опубликованным только потому, что запрос отправлен. Нужен подтверждённый publish result / release URL / фактическое появление поста.
