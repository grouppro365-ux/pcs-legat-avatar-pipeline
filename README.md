# PCS + Legat AI Avatar Pipeline

Бесплатный GPU-контур без собственного сервера для ежедневных роликов Premium Concierge Service Thailand и Legat Thailand Car.

## Что делает проект

1. Берёт мастер-портрет `6738.png` из **приватного** Kaggle Dataset.
2. Создаёт или принимает RU/EN озвучку.
3. Генерирует semi-body анимацию через EchoMimicV2.
4. Уточняет lip-sync через MuseTalk 1.5.
5. Собирает горизонтальный MP4 1920×1080 через FFmpeg.
6. Проверяет длительность, FPS, кодеки и размер через ffprobe.
7. Сохраняет результаты в `/kaggle/working/output`.

## Безопасность

Портрет, реальные фото машин, договоры, токены и другие личные материалы **не хранятся в этом публичном репозитории**. Для них создаётся приватный Kaggle Dataset `pcs-legat-private-assets`.

## Текущий этап

Сначала запускается короткий smoke test. Его задача — подтвердить, что бесплатный GPU Kaggle действительно тянет EchoMimicV2 и MuseTalk на текущем образе Kaggle. После успешного теста включается полный 30-секундный режим.

## Запуск в Kaggle

Открой `kaggle_avatar_pipeline.ipynb`, включи GPU и Internet, затем нажми **Run All**.

Ожидаемые входные файлы:

- `/kaggle/input/pcs-legat-private-assets/6738.png`
- необязательно: `voice_ru.wav`, `voice_en.wav`
- необязательно: `job.json` с текстами и настройками ролика.

Если аудио не приложено, notebook создаёт тестовую RU/EN озвучку через бесплатный Edge TTS. Для стабильной ежедневной работы лучше позднее положить готовые голосовые WAV в приватный Dataset.

## Выход

- `output/avatar_base.mp4`
- `output/avatar_ru.mp4`
- `output/avatar_en.mp4`
- `output/qa_report.json`
- `output/run_manifest.json`

## Ограничения бесплатного режима

Kaggle не гарантирует конкретный GPU и точное время старта. Поэтому pipeline останавливается с понятной ошибкой, если GPU отсутствует, не хватает VRAM или изменились зависимости upstream-моделей. Он не выдаёт неподвижную фотографию за готового аватара.
