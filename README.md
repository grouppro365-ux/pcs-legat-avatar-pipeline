# Agency Workbench — ChatGPT Free Mode v0.3.0

Браузерное расширение для Opera/Chrome: использует уже открытую вкладку ChatGPT как «мозг» и управляет явно привязанной рабочей вкладкой. OpenAI API не используется.

## Установка

1. Скачайте ZIP релиза и распакуйте его.
2. Откройте `opera://extensions`.
3. Включите режим разработчика.
4. Нажмите **«Загрузить распакованное»**.
5. Выберите папку, где **непосредственно лежит `manifest.json`**.
6. Нажмите значок Agency Workbench — откроется панель.

## Первый запуск

1. Откройте отдельный разговор ChatGPT для браузерной работы.
2. Откройте рабочий сайт в другой вкладке.
3. В Workbench нажмите «Обновить вкладки».
4. Привяжите конкретный ChatGPT.
5. Привяжите конкретный рабочий сайт.
6. Нажмите «Проверить bridge».
7. Нажмите **«Тест ChatGPT»**. PASS означает, что сообщение действительно ушло в выбранный разговор и ответ вернулся обратно в расширение.
8. Добавьте задачу и нажмите «Добавить и запустить».

## Что исправлено в v0.3.0

- content-script больше не предполагается установленным: background сначала делает PING, при отсутствии bridge внедряет `chatgpt-bridge.js` / `page-agent.js` через `chrome.scripting.executeScript`, затем делает повторный PING;
- привязывается конкретный `tabId` и конкретный URL разговора ChatGPT;
- при переключении на другой разговор задача останавливается;
- рабочий сайт привязывается по `tabId + origin`; переход на другой origin останавливает задачу;
- ChatGPT-команды защищены `requestId`, старые ответы не исполняются;
- `done` нельзя принять после действий без независимой проверки;
- все `fill/select` автоматически перечитываются из DOM перед `done`;
- опасные внешние действия требуют одноразового подтверждения пользователя;
- пароли, OTP, карты, банковские поля, API keys и токены заблокированы локальным кодом;
- внешние ссылки/формы cross-origin блокируются до клика;
- в page snapshot не передаются значения текстовых input;
- URL передаётся без query/hash;
- email/телефон/card/IBAN/token-подобные данные редактируются;
- verified route memory хранит только структуру маршрута, без введённых значений;
- лимит автономного цикла — 24 шага.

## Почему это бесплатно

Расширение не содержит `OPENAI_API_KEY` и не обращается к `api.openai.com`. Оно пишет управляющий запрос в обычный открытый ChatGPT через DOM браузера и читает новый ответ из той же вкладки.

## Важно

DOM ChatGPT может меняться со временем. Если кнопка «Тест ChatGPT» перестала проходить, журнал показывает, на каком этапе сломался bridge. Это не должно приводить к молчаливому выполнению в другой вкладке.
