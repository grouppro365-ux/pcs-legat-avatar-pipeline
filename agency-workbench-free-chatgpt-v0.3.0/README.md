# Agency Workbench — ChatGPT Free Mode v0.3.0

## Что исправлено

Главный runtime-баг v0.2.0: список вкладок мог успешно показывать и привязывать уже открытые страницы, хотя content-script расширения в этих вкладках отсутствовал. В результате UI выглядел рабочим, но команды не доходили ни до ChatGPT, ни до рабочего сайта.

v0.3.0 делает bridge self-healing:

1. При привязке сначала отправляется `PING`.
2. Если получаем `Receiving end does not exist` или другой no-listener error, service worker сам вызывает `chrome.scripting.executeScript`.
3. После внедрения выполняется повторный `PING`.
4. Привязка считается успешной только после реального ответа bridge.
5. То же выполняется перед каждым scan/action/send, поэтому перезагрузка страницы не ломает работу.

## Новая диагностика

В Workbench появились:

- зелёный/красный статус ChatGPT bridge;
- зелёный/красный статус page-agent;
- кнопка `Проверить bridge`;
- кнопка `Тест ChatGPT`, которая реально отправляет тестовую строку в привязанный разговор и ждёт ответ;
- подробный журнал: scan → prompt → response → parsed command → browser action/error.

Теперь «ничего не происходит» быть не должно: ошибка отображается прямо в журнале.

## Установка

1. Отключить или удалить v0.2.0.
2. Открыть `opera://extensions` или `chrome://extensions`.
3. Включить режим разработчика.
4. `Load unpacked / Загрузить распакованное` → выбрать папку `agency-workbench-free-chatgpt-v0.3.0`.
5. Нажать значок расширения — откроется Workbench.
6. Выбрать открытую вкладку ChatGPT и нажать `Привязать ChatGPT`.
7. Выбрать рабочий сайт и нажать `Привязать рабочий сайт`.
8. Оба статуса должны стать зелёными.
9. Нажать `Тест ChatGPT`. В журнале должен появиться `ChatGPT bridge полностью работает`.
10. После этого запускать реальную задачу.

**Обновлять уже открытые ChatGPT/WordPress вкладки после установки v0.3.0 не обязательно:** bridge умеет внедряться в них программно.

## Как работает выполнение

Один цикл = один browser action:

`scan рабочего сайта → отправка scan + задачи в открытый ChatGPT → один JSON action → выполнение → новый scan`.

ChatGPT не получает право выполнять произвольный JavaScript. Поддержаны только:

- `click`
- `fill`
- `select`
- `assertText`
- `assertUrl`
- `wait`

Publish/send/delete/payment-подобные клики требуют отдельного одноразового подтверждения в Workbench.

## Без платного API

Расширение не использует `api.openai.com`, OpenAI API key, n8n Cloud, Vercel или Neon. Reasoning выполняется через уже открытую веб-вкладку ChatGPT.
