AGENCY WORKBENCH — OPERA READY v0.3.1

1. Распакуйте скачанный ZIP.
2. Внутри будет одна папка: Agency-Workbench-Opera-v0.3.1
3. Откройте opera://extensions
4. Включите «Режим разработчика».
5. Нажмите «Загрузить распакованное».
6. Выберите папку Agency-Workbench-Opera-v0.3.1.

Внутри этой папки manifest.json лежит сразу в корне.

Первый запуск:
- откройте нужный разговор ChatGPT, откройте расширение и нажмите «Привязать ChatGPT»;
- откройте рабочий сайт, снова откройте расширение и нажмите «Привязать этот сайт»;
- нажмите «Тест ChatGPT»;
- введите задачу и нажмите «Выполнить».

Расширение не использует OpenAI API key: оно работает с уже открытой вкладкой ChatGPT.
